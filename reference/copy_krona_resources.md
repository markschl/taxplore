# Copy chart resources to a specified directory

The images and JavasScript files are unmodified snapshots of the
original files from the [Krona](https://github.com/marbl/Krona)
repository (master branch, commit d1479b3).

## Usage

``` r
copy_krona_resources(dest_dir)
```

## Arguments

- dest_dir:

  Target directory, which can be linked by multiple charts (see
  `resources_url` in
  [`ChartOpts()`](https://markschl.github.io/taxplore/reference/ChartOpts.md))
