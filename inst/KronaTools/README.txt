This folder contains an unmodified copy of files downloaded
from https://github.com/marbl/Krona

Directories:
- KronaTools/src
- KronaTools/img

These assets are included in the HTML charts generated by the
`generate_krona_html_internal()` function.

Snapshot version: d1479b3

In addition, a minified JS file is included to allow creating slightly smaller
HTML files with less lines (`minify = TRUE` argument):

KronaTools/src/krona-2.0.min.js

This is always used when embedding charts to improve performance and avoid
some problem during PDF generation.

Minified with https://github.com/mishoo/UglifyJS:
Program: /usr/bin/uglifyjs
Version: uglify-js 3.17.4
Command: uglifyjs inst/KronaTools/src/krona-2.0.js --mangle --mangle-props
